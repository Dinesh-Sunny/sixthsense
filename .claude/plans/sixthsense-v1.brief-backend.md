## backend brief (fastapi 0.143.3, pydantic 2.14.1, pydantic-settings 2.16.0, httpx 0.28.1, tenacity 9.2.1, uv 0.12.15)
Verified in a scratch venv (fastapi 0.143.3 / starlette 1.8.0) + httpx 0.28.1 source; (T) = executed. FastAPI release-notes bodies were unfetchable (0.143.0 Breaking Changes unread).
- [must] Lifespan owns every client and yields state: `async with httpx.AsyncClient(...) as vss: yield {"vss": vss}`; read via `request.state.vss` behind `Annotated[httpx.AsyncClient, Depends(get_vss)]` (T). fa-lifespan, fa-depends, fa-httpx-client. Cancel the run task after `yield`.
- [must] `create_app(settings: Settings | None = None)` factory, lifespan closes over `settings`; `dependency_overrides[get_settings]` does not reach lifespan. Tests pass `Settings(_env_file=None, ...)` + a `transport=` hook. fa-settings, fa-async-tests.
- [must] Settings: `SettingsConfigDict(env_file=".env", extra="ignore", validate_by_name=True, validate_by_alias=True)`. Default extra is forbid, so a stray `.env` key raises (T). `AliasChoices` makes the alias the only env name: list the field's own name too. `validate_by_name` lets tests pass `vss_url=` (T). `SecretStr` repr masked (T). Ref pydantic.dev/docs/validation/latest/concepts/config/.
- [must] VSSAuth overrides `async_auth_flow`, NOT `requires_response_body = True` (that makes httpx `await response.aread()` on every response incl. `send(stream=True)`, httpx/_auth.py:104, so the clip proxy would buffer whole videos in RAM; T). Pattern (T: refresh + streamed 206): login under `asyncio.Lock`, `await login_resp.aread()` only on login, set Bearer, `resp = yield request`; on 401 re-login and `yield request` once. Ref python-httpx.org/advanced/authentication/.
- [must] Clip proxy (T): `r = await vss.send(vss.build_request("GET", path, headers={"Range": rng}), stream=True)` -> `StreamingResponse(r.aiter_bytes(), status_code=r.status_code, headers={content-type, content-length, content-range, accept-ranges}, background=BackgroundTask(r.aclose))` -> 206 + Content-Range. Pass 404/416 through; other non-2xx -> 502 after `await r.aclose()`. Validate `source` startswith `s3://{bucket}/`, no `..`. Forward only Range/If-Range. Route `-> StreamingResponse`, no response_model. fa-streaming, hx-stream, hx-range.
- [must] Don't rely on Starlette slash redirects behind the `/app(/|$)(.*)` rewrite: `/incident` -> `Location: /incident/` without `/app`, even with `root_path="/app"` (T). Keep `trailingSlash: true`, slash links only, convention test on web hrefs. `uvicorn --root-path /app --forwarded-allow-ips="*"` documented, untested. fa-staticfiles.
- [must] Run job: `asyncio.create_task` kept on app.state (strong ref) + `add_done_callback` recording state="error" (exception class only). Single-flight `if task and not task.done(): return current` (no await between check/set). TaskGroup cancels siblings on first failure: catch per item or `gather(return_exceptions=True)`; keep `Semaphore(3)`. Wrap each GPU call in `asyncio.timeout(settings.step_timeout)` (httpx read timeout is per chunk). aq-simple-or-arq, hx-timeout.
- [must] Boundary validation: `mode: Literal[...]`/enum; `limit: int = Field(ge=1, le=10)`; `AskIn.question` min_length=1, max_length=500; request models `extra="forbid"`; `POST /api/alerts` idempotent per incident_id (no second Discord post); `@app.exception_handler(httpx.HTTPError)` -> 502 fixed message, never echo upstream bodies. fa-model-config, fa-response-model.
- [should] Upstream models `extra="ignore"`, defaulted fields; `Field(validation_alias=AliasChoices("start_time","start"))` replaces `first()`. Outward routes use return annotations; conventions test walks app.routes, exempting /api/clip, /healthz, the mount.
- [should] Retries on idempotent calls only: `AsyncRetrying(stop=stop_after_attempt(4), wait=wait_exponential_jitter(initial=0.5, max=8), retry=retry_if_exception(is_transient), reraise=True, before_sleep=before_sleep_log(log, WARNING))`; is_transient = TransportError or HTTPStatusError 429/>=500 (T). Not on Discord POST. Do not wrap openai calls (SDK max_retries=2). tn-async-retrying, tn-wait-jitter, tn-retry-if.
- [should] Per-upstream clients: GPU `Timeout(10, read=120)`; Open-Meteo `Timeout(3)` + clock fallback; `Limits(max_connections=20, max_keepalive_connections=10)` >= gpu_concurrency x fan-out; event hook logs method/host/status/ms only. hx-limits, hx-event-hooks.
- [should] Weather cache `(expires_at, Weather)` + `asyncio.Lock` (one call per burst), serve stale on error, `Cache-Control: public, max-age=600` via `response: Response`.
- [should] `/readyz` reuses cached token state, store ping via `to_thread` with 2 s timeout, cached ~10 s; `/healthz` no I/O. fa-health.
- [should] Static mount `StaticFiles(directory=settings.web_dir, html=True)` mounted last, default `check_dir=True`; `web_dir` setting (e.g. `/srv/web/out`, `--no-editable` breaks `__file__` paths). Skip `app.frontend()` (fa-frontend untested) and GZipMiddleware for the slice.
