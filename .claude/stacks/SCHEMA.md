# Stack registry & outline schema (cold reference)
Read by `stack-expert`, `feature-architect` and `feature-reviewer`; the always-loaded summary is `.claude/rules/stacks.md`.
Related stacks: none (repo tooling)
- Registry row (`README.md` › `## Stacks`): `| stack | packages | version | docs | outline |
  ai_tooling | choke point | health |`; cells never contain `|`. `packages` = comma-separated
  exact dep names. `version` = `uv.lock:<pkg>` | `pnpm-lock:<pkg>` | `compose:<service>` |
  `tool:<name>`. `outline` = `<stack>` | `none (utility)`. `choke point` = `<import> → <path>` | `—`.
  `health` free text; scouted deps carry `admitted YYYY-MM-DD`. [guard: N1 every declared dep
  has a row, N2 outline or utility + no orphans, N7 choke point = one importer]
- `ai_tooling` = `;`-separated `mcp:<server>` (wired in `.mcp.json`), `mcp?:<server> <url>`,
  `skill:<owner>/<repo>` (locked), `skill?:<url>`, `llms:<url>`, `cli:<cmd>`,
  `agents-md:<path|url>`, or `none (checked YYYY-MM-DD)`. [guard: N4 mcp wired, N5 skills locked]
- Outline = `lib/<stack>.yaml` (PORTABLE: no repo paths [N3], no statuses) + `usage/<stack>.yaml`
  (this repo) → `view/<stack>.md`, GENERATED by `stacks.sh view [stack…]`; never hand-edit a view.
- Unregistered libs are shared outlines synced from the template: no view until a row adopts them.
- lib top: `stack` (= file stem), `version` (QUOTED str), `docs_base` (https, no trailing `/`),
  optional `docs_bases: {name: https-base}`, `source`, `fetched`/`verified` (bare ISO dates),
  `toc`, `groups` (ordered; `groups[0].title` = `AI tooling`), optional `skipped`. Group `{title, sections}`. Section
  `{id, title, level: basic|intermediate|advanced, requires: [ids | <stack>:<id>], ref, entries}`.
- Entry: `id, name, summary (≤140), lenses (⊂ standards.md Lenses), ref` + optional `import,
  signature, params/options [{name, type, default: str|null, desc}], returns,
  since (quoted), deprecated (why/replacement), notes [portable facts only]`.
- Ids kebab-case, unique per lib (sections + entries). `ref` = `/path` (under docs_base) |
  `https://…` | `mcp:<server>/<path>` | `<docs_bases key>:/path`. No other/dup keys.
- usage: `entries: {<id>: {status, paths, note, why}}` (note/why ≤160, never "planned…"); status
  `used` (needs `paths`) | `candidate` | `n/a` (needs `why`) | `deprecated`; ids exist in the lib;
  absent = unassessed. Repo notes here, never in the lib. Outlines change only in /feature Learn.
  [guard: N3 `stacks.sh guards`]
- Coverage: `toc: [{index, match, exclude?, why?, base?}]` = live doc indexes (llms.txt,
  sitemap, ToC page; `base` + a GitHub tree API index for repo docs) and the in-scope page regex
  (`exclude` needs `why`). Every in-scope page is a section/entry ref or a `skipped: [{page, why}]`
  item; never drop one silently. [guard: N3 validate (schema); `stacks_coverage.sh` = outline
  modes' exit gate + `stacks_check.sh` report (network, so not in pytest)]
- Provenance: only docs fetched that session (skeleton from the live ToC), never memory; fetch
  an entry's ref before coding against it. (unenforced offline: `stacks_check.sh` resolves refs)
- Stale: `version` ≠ installed or `verified` >90 days → unverified until refreshed. [nudge: `stack_drift.sh`]
- Auto-refresh: hook runs `stacks_refresh.sh` ≤weekly in background; headless `stack-expert`
  (`dontAsk`, scoped rules) only for drifted/broken-ref stacks, worktree → branch
  `chore/stacks-refresh-*` if guards pass. (unenforced: script review)
- Run everything via `.claude/skills/feature/scripts/stacks.sh` (parser, validators, renderer, `guards`).
